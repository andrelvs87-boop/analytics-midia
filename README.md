# analytics-midia

Mídia pública dos reels do Instagram da Analytics Contabilidade.

Cada reel vive em `reels/<slug>/` com `reel.mp4` e `capa.png`. O Instagram
busca esses arquivos por URL quando publica, então o repositório precisa ser
público e o GitHub Pages precisa servir `video/mp4`.

Serve também o site estático? Não. Só mídia.
